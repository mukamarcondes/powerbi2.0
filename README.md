# Conectel BI Operacional

Painel web para acompanhar clientes, receita mensal, vendas, pagamentos, cancelamentos e downgrades da operação Conectel.

## Recursos principais

- Login com Supabase Auth
- Perfis de acesso: admin e visualizador
- Dashboard operacional
- Cadastro e importação de clientes
- Vendas mensais e pagos mensais
- Cancelamentos e downgrades por mês
- CRUD administrativo com persistência no Supabase

## Banco de dados

O schema inicial está em `supabase/schema.sql`.
